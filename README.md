# Amazon Customer Reviews Analysis

## Summative Lab: NLP, Time Series, and Neural Networks

This project analyzes Amazon customer reviews using three data-science approaches:

1. Natural Language Processing (NLP) to clean and explore review text.
2. Time-Series Analysis and Forecasting to assess changes in review activity and customer ratings over time.
3. Neural Networks to predict customer rating classes from review text.

The analysis is implemented in a Jupyter Notebook and structured around the assignment's `# TODO:` prompts. Additional diagnostics and model-evaluation steps are included to align the work with the highest rubric criteria.

## Project Objectives

The project aims to:

- Build a reproducible text-preprocessing pipeline.
- Identify frequent words, bigrams, trigrams, and sentiment-specific language patterns.
- Analyze monthly review volume and average customer ratings.
- Test stationarity and transform the time series where necessary.
- Compare several ARIMA specifications using fit and forecast-performance measures.
- Generate a future review-volume forecast with uncertainty intervals.
- Convert review text into TF-IDF features.
- Build and compare multilayer neural networks for five-class rating prediction.
- Evaluate model performance using class-level metrics, a confusion matrix, and a baseline comparison.
